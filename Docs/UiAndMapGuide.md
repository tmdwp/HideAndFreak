# UI 수정과 맵 제작 안내

## UI 수정

UI는 프리팹으로 관리합니다. **"테스트 환경 생성"·"맵 생성"을 다시 실행해도 프리팹을 고친 내용은 유지**됩니다.

| 프리팹 (`Assets/_Project/Prefabs/UI`) | 내용 | 쓰이는 곳 |
|---|---|---|
| `SettingsPanel` | 설정 화면 (그래픽/사운드/조작 키 탭) | 로비, 룸·게임의 ESC 메뉴 (중첩 프리팹이라 한 번 고치면 모두 반영) |
| `CreditsPanel` | 크레딧 화면 | 로비 |
| `LobbyCanvas` | 로비 화면 전체 | 로비 씬 |
| `RoomCanvas` | 룸 화면 전체 + ESC 메뉴 | 룸 씬 |
| `HudCanvas` | 게임 HUD + ESC 메뉴 + 결과 화면 | 모든 게임 맵 |

### 고치는 방법
- 프리팹을 더블클릭해 열고 이미지(Image의 Source Image), 색, 폰트, 크기, 위치를 바꾸면 됩니다.
- **버튼·텍스트 오브젝트를 지우거나 다른 종류로 바꾸지 마세요.** 화면 코드가 인스펙터로 연결해 쓰고 있어, 지우면 그 기능이 동작하지 않습니다. 모양만 바꾸고 오브젝트는 남겨 두는 것이 안전합니다.
- 화면 코드는 캔버스 오브젝트에 영역별로 나뉘어 붙어 있습니다. 버튼 연결을 바꿀 때는 해당 영역의 컴포넌트를 찾으면 됩니다.

  | 캔버스 | 화면 관리 | 영역별 코드 |
  |---|---|---|
  | `LobbyCanvas` | `LobbyView` (화면 전환, 뒤로·ESC, 상태 문구), `CursorUnlockOnStart` | `LobbyMainMenu`(메인 버튼), `LobbyCreateMenu`(방 만들기·스팀 방 만들기), `LobbyJoinMenu`(참가·스팀 방 입장·IP 참가) |
  | `RoomCanvas` | `CursorUnlockOnStart` | `RoomMemberListView`(참가자), `RoomCodeView`(방 코드·초대), `RoomSettingsView`(게임 설정), `RoomFooterView`(시작/준비·나가기·상태) |
  | `HudCanvas` | `GameHud` (게임 상태 연결, 조준점·대기 문구) | `HudTopPanel`(상단 중앙: 단계·시간·마네킹 수), `HudControlsPanel`(중앙 좌측: 조작 키), `HudObjectivePanel`(중앙 우측: 목표), `HudStaminaBar`(하단 중앙: 스태미나), `HudBottomPanel`(하단: 체력·도구·관전), `HudResultPanel`(결과) |
  | `SettingsPanel` | `SettingsPanelView` (탭, 닫기) | 페이지별 `DisplaySettingsSection`, `LanguageSettingsSection`, `SoundSettingsSection`, `ControlSettingsSection` |

- **로비 화면 추가**: `LobbyScreen`에 값을 끝에 추가하고, `LobbyView`의 화면 목록(Screens)에 (화면, 패널, 뒤로 가면 돌아갈 화면)을 등록합니다. 첫 항목이 시작 화면입니다. 코드는 바꾸지 않아도 됩니다.
- HUD에 새 영역을 추가하려면 `IHudSection`을 구현한 컴포넌트를 HUD 캔버스(또는 그 아래)에 붙이면 `GameHud`가 자동으로 갱신합니다.
- 문장은 `Resources/Localization/strings.csv`에서 바꿉니다. 텍스트에 붙은 `LocalizedText`의 key가 문장 이름입니다.
- **폰트**: 기본 폰트(LegacyRuntime)인 텍스트만 실행 시 OS 한글 폰트로 바뀝니다(`OsFontApplier`). 직접 폰트를 지정한 텍스트는 그대로 둡니다. 캔버스의 `OsFontApplier`에 폰트 에셋을 넣으면 기본 폰트 텍스트를 모두 그 폰트로 바꿉니다.
- 설정 탭의 선택/기본 색은 `SettingsPanelView`의 Selected/Normal Tab Color에서 바꿉니다. (탭 버튼에 이미지를 넣었다면 흰색으로 두면 이미지 색 그대로 보입니다)

### 새 UI 영역 받기
- 코드에 HUD 영역이나 키 설정 항목이 새로 생기면 메뉴 **GuardVsMannequin > UI > 빠진 UI 영역·키 줄 추가**를 실행합니다. 지금 프리팹은 그대로 두고 없는 영역(HUD 조작 안내·목표·스태미나 막대, 설정 화면의 새 키 줄)만 더합니다. 여러 번 실행해도 됩니다.
- 조작 안내의 키 이름은 키 설정을 따릅니다. 마우스 버튼 등 표시 이름은 `strings.csv`의 `input.<장치>.<컨트롤>`(예: `input.mouse.leftButton`)에서 바꿉니다.

### 주의
- 게임 설정 항목(`game_settings.csv`)을 추가하면 룸 화면 줄 수가 달라지므로 `RoomCanvas`를 다시 만들어야 합니다.

### 초기화 기준
- 마음에 드는 모양으로 고쳤으면 메뉴 **GuardVsMannequin > UI > 현재 UI를 초기화 기준으로 저장**을 실행합니다. 프리팹 5개가 프로젝트 루트의 `UiDefaults/` 폴더에 기준본(.prefab + .meta)으로 복사됩니다. (Assets 밖이라 Unity 프로젝트 창에는 보이지 않으며, git에 함께 커밋합니다)
- **UI > UI 프리팹 초기화 (저장한 기준으로 되돌리기)**: 기준본 내용으로 프리팹을 덮어씁니다. GUID가 같아 씬을 다시 만들 필요가 없습니다. 기준본이 없는 프리팹만 지워지고, "테스트 환경 생성" → "맵 생성" 때 코드 기본 모양으로 다시 만들어집니다.
- 프리팹 파일이 없어 다시 만들어야 할 때도 기준본이 있으면 코드 대신 기준본을 씁니다.
- **UI > UI 프리팹 초기화 (코드 기본 모양, 기준본 무시)**: 프리팹과 기준본을 모두 지웁니다. 이후 "테스트 환경 생성" → "맵 생성"을 실행하면 코드 기본 모양으로 만들어집니다.
- 이미 만들어진 씬은 프리팹 인스턴스를 쓰므로, 프리팹을 고치면 씬을 다시 만들지 않아도 반영됩니다.

## 맵 제작

메뉴 **GuardVsMannequin > 맵 제작 > 맵 제작 도우미** 창에서 위에서부터 순서대로 진행합니다.

1. **새 맵 만들기**: 이름을 영문으로 넣으면 `Scenes/Custom/Map_<이름>.unity`가 만들어집니다. 게임 시스템, UI, 투명 경계, 기본 지점, 조명 제어가 들어 있습니다.
2. **모델 배치**: 맵 모델을 `Map/Environment` 아래에 넣습니다. 시작용 바닥은 지워도 됩니다. (사람 키 1.8m 기준)
3. **등록** (Hierarchy에서 선택 후)
   - 충돌체 추가: 걸어 다닐 바닥·벽·사물. 충돌체가 없으면 통과되고 가짜 마네킹이 다니지 못합니다.
   - 변신 사물로 등록: 선택한 오브젝트(자식 조각 포함)를 그 모습 그대로 복사해 변신. 여러 조각으로 된 가구는 **부모를 선택**하세요. 가장 긴 변이 3m(`game_tuning.csv`의 `DisguiseMaxSize`)를 넘으면 변신할 수 없습니다. 파티클·조명·애니메이션은 복사되지 않습니다.
   - 벽으로 등록: 크기와 관계없이 고정 크기 벽 조각(1.2×2×0.25m)으로 변신. 큰 벽에 사용합니다. / 등록 해제
   - 사물 번호는 씬을 저장할 때 자동으로 매겨집니다. 직접 바꾸지 마세요.
   - 조명 등록: 사냥 시간에 꺼지는 조명(MapLight)이 됩니다. 구운(Baked) 조명은 쓰지 마세요.
4. **지점 배치**: 씬 뷰 화면 중앙 아래 바닥에 전원 장치 후보·마네킹 스폰·가드 스폰 후보를 추가하고 이동 도구(W)로 옮깁니다. 전원 장치 후보는 "넓게 다시 배치"로 자동 배치할 수도 있습니다.
   - 권장 개수: 전원 장치 후보 12개, 마네킹 스폰 9개, 가드 스폰 후보 5개
   - 가드는 판마다 마네킹 스폰 지점에서 먼 곳(가드 스폰 후보 + 바닥(NavMesh) 무작위 위치)에서 시작합니다. 가드 스폰 후보는 마네킹 스폰과 20m 이상 떨어뜨리고, 마네킹 스폰이 직접 보이지 않는 곳에 두세요. (거리는 `game_tuning.csv`의 `GuardSpawnMinDistance`)
5. **경계 맞추기**: 투명 벽·천장을 모델 크기에 맞춥니다.
6. **검사**: 빠진 것을 오류/경고로 보여줍니다. "선택"을 누르면 해당 오브젝트로 이동합니다.
7. **최적화**: 경계 밖 제거, 오클루전 컬링 굽기. 씬을 저장한 뒤 실행합니다.
8. **맵 목록 갱신**: 빌드 설정, 룸의 맵 목록, 맵 이름 문구(`strings.csv`의 `map.<번호>`, 처음에는 씬 이름으로 들어감), 맵 설정 범위를 맞춥니다.

### 참고
- 맵 번호는 테스트 맵(0) → 자동 생성 맵 4개(1~4) → `Scenes/Custom`의 맵(파일 이름 순)입니다. 직접 만든 맵을 추가·삭제하면 뒤 번호가 바뀌므로 "맵 목록 갱신"을 다시 실행하고 `strings.csv`의 맵 이름을 확인하세요.
- 맵별 마네킹/가드 외형은 `Map` 오브젝트의 `MapInfo`에서 고릅니다.
- 천장이 없는 맵은 투명 천장이 경계에 포함되어, 벽을 타고 밖으로 나가지 못합니다.
- 전원 장치·스폰 지점은 씬 뷰에 색 상자와 이름표로 표시됩니다.
